# Моя коллекция

Локальный каталог монет и банкнот. Фотографии из архива сгруппированы по номеру: `1_1` и `1_2` — две стороны предмета № 1.

## Запуск в Windows

Откройте PowerShell в папке проекта и выполните:

```powershell
npm.cmd install
npm.cmd run dev
```

Затем откройте адрес, который появится после строки `Local` (обычно `http://localhost:3000`).

## Проверка сборки

```powershell
npm.cmd run build
```

Проект настроен только для локальной работы. Публикацию можно будет добавить позже, когда каталог и оценки будут готовы.
